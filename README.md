# Карпати без клопоту

Багатосторінковий адаптивний сайт туристичного проєкту «Карпати без клопоту».

## Сторінки
- `index.html` — головна
- `tours.html` — три туристичні пакети
- `about.html` — концепція та організаційна інформація
- `booking.html` — форма заявки
- `contacts.html` — контакти та FAQ

## Запуск локально
Найпростіше — відкрити `index.html` у браузері. Для локального сервера можна скористатися розширенням Live Server у Visual Studio Code.

## Публікація на GitHub Pages
1. Створи новий публічний репозиторій на GitHub, наприклад `karpaty-bez-klopotu`.
2. Розпакуй архів і завантаж усі файли та папки в корінь репозиторію.
3. Відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**.
5. Обери гілку `main` та папку `/ (root)`, натисни **Save**.
6. Після завершення публікації GitHub покаже адресу сайту у форматі `https://USERNAME.github.io/karpaty-bez-klopotu/`.

## Важливо про форму бронювання
Сайт є статичним і не має серверної бази даних. Форма перевіряє обов'язкові поля, формує лист із деталями заявки та відкриває поштовий клієнт користувача через `mailto:`. Заявка не відправляється автоматично й не зберігається на сайті. Для реального приймання бронювань без поштового клієнта потрібно підключити сервіс обробки форм або власний backend.

## Контент і ціни
- Тривалість пакетів 2, 3 і 4 дні взято з бізнес-плану.
- 7 000 грн для триденного туру — модельна ціна з бізнес-плану, а не підтверджена пропозиція.
- Для дводенного та чотириденного турів ціна не визначена в бізнес-плані, тому на сайті вказано «за запитом».
- Точні маршрути, календар виїздів, телефон, соціальні мережі та остаточний склад послуг у вихідному бізнес-плані не визначені, тому вони не вигадувалися.
